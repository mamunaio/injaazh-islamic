# 🌙 Injaazh Islamic - Your Ultimate Deen Companion

[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen.svg)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.1.0-blue.svg)](https://kotlinlang.org)
[![Compose](https://img.shields.io/badge/Jetpack-Compose-orange.svg)](https://developer.android.com/jetpack/compose)

**Injaazh Islamic** is a premium, feature-rich, and modern Android application designed for devout Muslims. Built with the latest Android technologies, it provides an elegant and space-efficient interface to manage your daily worship, knowledge, and spiritual growth.

---

## ✨ Key Features

### 🕌 Precision Prayer Times & Adhan
- **Exact Alarms:** High-accuracy prayer timings using dedicated GPS.
- **Dynamic Countdown:** A beautiful circular timer showing time remaining for the next prayer.
- **Forbidden Times (Makruh):** Clearly highlighted periods when praying is prohibited.
- **Auto-Reschedule:** Adhan alerts stay active even after device reboots.

### 📖 Advanced Al-Quran
- **Modern UI:** Clean list of 114 Surahs with Arabic and Bengali meanings.
- **Uthmani Script:** High-quality Arabic rendering for comfortable reading.
- **Audio Recitation:** Gapless audio streaming for every Ayah with background playback support.

### 📈 Smart Prayer Tracker
- **Horizontal Pill-Tracker:** Mark your daily prayers (Fajr, Dhuhr, etc.) in a space-optimized layout.
- **Visual Progress:** Animated donut charts showing your weekly and monthly worship statistics.
- **Local Privacy:** All your tracking data is stored securely on your device using Room DB.

### 📿 Digital Tasbih & Duas
- **Tactile Feedback:** Haptic vibration on every tap to simulate a physical Tasbih.
- **Auto-Save:** Progress persistence using Jetpack DataStore.
- **Hisnul Muslim:** A categorized collection of authentic Duas and Azkar with Bengali translation.

### ⚖️ Zakat Calculator & Education
- **Real-time Assets Calculation:** Instantly calculate Zakat based on gold, silver, cash, and liabilities.
- **Education Hub:** Learn the 99 Names of Allah, Kalimas, and Wudu/Sunnah guides through a premium grid interface.

---

## 🛠 Tech Stack

- **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3)
- **Architecture:** Clean Architecture + MVVM
- **Dependency Injection:** [Hilt](https://dagger.dev/hilt/)
- **Database:** [Room](https://developer.android.com/training/data-storage/room)
- **Networking:** [Retrofit](https://square.github.io/retrofit/)
- **Audio:** [Media3 ExoPlayer](https://developer.android.com/guide/topics/media/media3)
- **Persistence:** [Jetpack DataStore](https://developer.android.com/topic/libraries/architecture/datastore)
- **Calculation:** [Adhan-Java API](https://github.com/batoulapps/adhan-java)

---

## 📸 Premium Design Philosophy
Unlike traditional apps, **Injaazh Islamic** uses:
- **Glassmorphism:** Elegant semi-transparent surfaces.
- **Dynamic Theming:** Deep Emerald & Gold accent colors.
- **Space Efficiency:** Widget-based dashboard to minimize scrolling.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mamunaio/injaazh-islamic.git
   ```
2. Open the project in **Android Studio Ladybug (or newer)**.
3. Add your `google-services.json` (if needed for Firebase).
4. Build and Run!
